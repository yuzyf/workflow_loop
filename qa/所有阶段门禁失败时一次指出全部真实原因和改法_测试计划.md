## 2. 针对性回归范围

- 回归门禁命令层对既有字符串错误和新增结构化诊断的合并，防止修复一种错误时吞掉另一种仍有效错误。
- 回归验收索引、固定字段、缺陷主题、实施基线和实施记录位置五个已复现入口，保证严格格式没有被放宽。
- 回归完整实施范围快照，保证计划集合只判断“允许改什么”，观察集合仍能发现未登记源码、测试、脚本和配置变化。

## 3. 测试条件要求

- 使用项目现有 Python 虚拟环境、pytest 测试框架和临时目录 fixture；测试只写 pytest 提供的隔离目录，不访问外部服务，不修改真实用户数据。
- 每个测试项使用精确 pytest 节点登记，报告适配器使用 `pytest-junitxml`（pytest JUnit XML 结构化报告解析器），超时 120 秒，工作目录为项目根。
- 项目全量测试入口已经按操作系统登记：Windows 使用 `.venv\\Scripts\\pytest.exe`，Linux 和 macOS 使用 `scripts/test_all.sh`；本阶段范围确认不执行全量入口。

## 4. 未决测试条件

- 暂无。AC-01 至 AC-06 均有可自动判断的输入、动作、观察位置和通过标准，不需要外部服务或人工判断。
