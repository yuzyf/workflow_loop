## 2. 针对性回归范围

- 回归现有全局命令身份和安装命令搜索路径记录，避免全局卸载删除其它软件或用户预先存在的路径。
- 回归项目根解析和未安装项目错误路径，确认全局卸载不依赖项目骨架存在。
- 回归 Windows UTF-8 输出和进程退出处理，避免 PowerShell 5.1 把 uv 正常标准错误进度文字当成失败。

## 3. 测试条件要求

- Python 3.11 或更高版本、项目现有 `pytest` 环境，以及与开发电脑真实命令完全隔离的 uv 工具目录、命令目录和命令搜索路径配置样本。
- 可记录目录访问和注入删除失败的测试替身，用于证明没有扫描项目并准确报告部分失败。
- GitHub 托管 Windows Server，分别提供 Windows PowerShell 5.1 和 PowerShell 7；远端作业执行前另行取得用户确认。
- 新增测试命令、测试文件、样本和证据位置在实施后确认。

## 4. 未决测试条件

- 当前已经确定但尚未执行：本地全局范围自动化测试和 Windows PowerShell 5.1、7 自卸载作业。
