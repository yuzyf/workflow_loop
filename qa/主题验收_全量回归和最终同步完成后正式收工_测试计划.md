## 2. 针对性回归范围

- 回归自动化、人工和混合验收记录，以及失败后当前结果文件清除。
- 回归缺陷从主题验收到最终回归、整体验收的状态变化，原始复现内容始终不被覆盖。
- 回归最终全量测试、整体验收、最终代码设计同步和正式收工之间的阶段顺序。

## 3. 测试条件要求

- Python 3.11 及以上、`pytest>=7`，并已完成各主题正式测试所需环境。
- 最终全量入口按系统使用项目虚拟环境：macOS 与 Linux 为 `.venv/bin/python -m pytest -q`，Windows 为 `.venv\Scripts\python.exe -m pytest -q`。
- 当前主题验收的人工部分只覆盖 TC-01，需要用户核对主题验收是否复用当前有效的自动化证据，并准确记录人工回答。
- 整体验收和最终代码设计核对分别由后续的整体验收环节和最终代码设计同步环节实际执行，不在当前主题验收中提前询问。

## 4. 未决测试条件

- 当前已经确定但尚未执行：全部主题完成后的最终全量测试、整体验收和最终代码设计同步；这些是后续环节的真实动作，不是 TC-05 或 TC-06 在当前主题验收中的人工测试步骤。
- 只有实施代码完成后才能确定：最终代码设计中的真实新增代码位置和测试位置。
- 验收条件本身无法验证：暂无。
