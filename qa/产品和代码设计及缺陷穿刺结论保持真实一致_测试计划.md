## 2. 针对性回归范围

- 回归产品设计哈希只覆盖当前链接功能文档，保留的已移除历史文档不能冒充当前功能。
- 回归代码设计初始化、设计期修订、穿刺设计影响和最终同步使用同一架构文档。
- 回归旧工作流穿刺基线兼容、当前轮次校验、阻塞结论和临时目录清理。

## 3. 测试条件要求

- Python 3.11 及以上、`pytest>=7`，以及可创建中文和冲突路径的临时文件系统。
- 真实穿刺根据具体不确定性提供真实接口、文件、平台或数据；涉及外部写入时另行取得用户确认。
- 人工部分需要用户核对产品内容、架构职责、根因和穿刺证据是否支持结论。

## 4. 未决测试条件

- 当前已经确定但尚未执行：正式中文路径迁移后的全项目链接扫描。
- 只有实施代码完成后才能确定：统一产物路径模块、缺陷文件标识和穿刺文件标识的最终测试入口。
- 验收条件本身无法验证：暂无。
