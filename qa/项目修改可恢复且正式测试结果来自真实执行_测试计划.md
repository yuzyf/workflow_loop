## 2. 针对性回归范围

- 回归现有实施门禁、计划哈希、接受现有代码和测试代码基线，删除不能真实恢复的纯哈希做法。
- 回归 Python、C++、Qt、JavaScript 等测试文件分类和 `Workflow-Test` 追踪标识解析。
- 回归主题依赖执行、失败阻断、结果文档校验和受影响主题当前记录失效。

## 3. 测试条件要求

- Python 3.11 及以上、`pytest>=7`，并允许测试进程创建和终止子进程。
- macOS、Linux 和 Windows CI；Windows 测试需要能够检查整个进程树已经结束。
- 使用隔离临时项目和临时回退目录，不修改当前真实轮次的生产代码副本。

## 4. 未决测试条件

- 当前已经确定但尚未执行：Windows 原生进程树终止和三平台参数保真测试。
- 只有实施代码完成后才能确定：跨平台执行器和扩展回退清单的最终测试函数与证据位置。
- 验收条件本身无法验证：暂无。
