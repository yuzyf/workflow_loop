## 2. 针对性回归范围

- 回归整轮作废命令，确认项目卸载不会复用回退恢复逻辑或改写业务内容。
- 回归首次安装、重复安装和残缺骨架判断，确认卸载后的干净目录能重新安装，部分残留不会被首次安装静默覆盖。
- 回归项目根解析和路径安全检查，避免删除符号链接目标或当前项目外内容。

## 3. 测试条件要求

- Python 3.11 或更高版本、项目现有 `pytest` 环境、临时项目目录、隔离全局工具目录，以及可控制删除失败的文件系统替身。
- 临时项目需要覆盖完整骨架、三个轮次状态、部分残留、定制 `AGENTS.md`、业务文件和正式产物。
- GitHub 托管的 macOS、Linux 和 Windows 环境用于运行两个旧版本卸载脚本；远端作业执行前另行取得用户确认。
- 新增测试命令、测试文件、样本和证据位置在实施后确认。
