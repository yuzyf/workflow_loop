# topic_execution_standard.md

按主题执行阶段规范词：该阶段位于实施计划之后、最终全量回归之前。全部主题都完成实施、测试和主题验收后，本阶段才能完成。

固定要求：

- 每个已确认主题都必须有实施记录、主题测试结果和主题验收结果。
- 主题测试结果必须写当前工作流编号和“测试结果：通过”。
- 主题验收结果必须写当前工作流编号和“验收结果：通过”。
- 主题执行阶段不能新增、删除、改名或合并验收主题，不能降低验收条件。
- 阶段确认时，程序更新 `traceability.md` 的实施记录、测试结果和验收结果列。
- 修 bug 时，程序追加缺陷的主题验收结果；主题验收通过不等于缺陷已经关闭。

测试项、测试数据、实施任务和主题内部文档结构由对应阶段的材料决定，本规范不提前定义这些细节。
