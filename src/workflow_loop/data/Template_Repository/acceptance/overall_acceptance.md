# overall_acceptance_prompt.md

整体验收阶段提示词：最终全量回归通过后，由用户确认整个需求是否达到验收计划中已经确认的结果，并把结论写入 `acceptance/overall_result.md`。

结果文件至少写清：

- 工作流编号：<当前 workflow_id>
- 整体验收状态：通过 | 未通过

只有用户确认整个需求已经达到验收计划中的结果时才写“整体验收状态：通过”，否则写“整体验收状态：未通过”。代码门禁会先重新检查最终全量回归状态，再读取这个固定字段；门2通过后仍必须由用户执行第三道确认门禁，AI 不能代替用户确认。阶段确认后，程序把整体验收结果写入 `traceability.md`；修 bug 时同时把缺陷状态更新为“已修复并验收”。
