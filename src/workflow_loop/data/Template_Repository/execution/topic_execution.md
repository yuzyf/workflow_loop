# topic_execution_prompt.md

按主题执行阶段提示词：按照已经确认的实施计划，分别推进各主题的实施、测试和主题验收。独立主题可以分别推进；有关联的主题遵守实施计划中已经写明的依赖顺序。

每个主题完成后，必须留下：

- `impl/` 下的实施记录，说明实际修改了什么代码。
- `qa/<主题>_result.md`，并写明当前工作流编号和“测试结果：通过”。
- `acceptance/<主题>_result.md`，并写明当前工作流编号和“验收结果：通过”。

所有主题都完成后再确认本阶段。阶段确认后，程序会把测试计划、实施记录、测试结果和主题验收结果写入项目根 `traceability.md`。修 bug 时，程序同时把缺陷记录更新为“主题验收通过，待全量回归”；不能在这里直接关闭缺陷。

本阶段不修改产品需求、验收主题或验收条件。测试计划的具体测试项和测试方法由 `test_plan` 阶段决定，本文件不替代测试计划。
