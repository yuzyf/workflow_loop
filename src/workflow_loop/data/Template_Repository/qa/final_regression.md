# final_regression_prompt.md

最终全量回归阶段提示词：全部主题分别完成实施、测试和主题验收后，对全部已合并代码执行一次全量回归，并把实际结果写入 `qa/final_regression_result.md`。

结果文件至少写清：

- 工作流编号：<当前 workflow_id>
- 回归状态：通过 | 失败

通过时写“回归状态：通过”，失败时写“回归状态：失败”，不能用“基本通过”或其他说法代替。程序只允许当前工作流编号且明确通过的结果进入整体验收，并在阶段确认后把回归结果链接写入 `traceability.md`。

修 bug 时，回归失败会把缺陷状态更新为“回归失败，重新处理中”；回归通过也不能直接关闭缺陷，还必须经过整体验收。具体测试范围、测试证据格式和失败后的实施细节，等测试流程讨论时再确定。
