# 产品版本策略：0.1.0 后使用新版本号

## 状态

原“产品版本永久固定为 `0.1.0`”决定已于 2026-08-04 被本文件中的新决定取代。

## 原决定

第一版只承认 `0.1.0`，不设计后续版本、多版本调度或项目升级，以缩小第一版的版本管理范围。这个决定同时承认 `workflow-loop==0.1.0` 发布到 PyPI 后不能覆盖或再次正式发布，并要求未来发布修改前先撤销永久固定版本的规则。

## 当前决定

本次正式发布仍统一使用 `0.1.0`：Python 分发包、GitHub 标签、命令身份、安装脚本和项目安装版本必须保持一致。PyPI 上的 `workflow-loop==0.1.0` 只能发布一次，发布后不能删除、覆盖或重发。

以后需要再次公开发布修改时，每次都必须选择一个尚未被 PyPI 占用的新版本号，并把全部公开版本身份统一更新为该版本号。本轮只改正版本发布规则，不实现项目升级、多版本调度、兼容版本范围或迁移系统；这些能力只有在后续需求明确需要时才另行设计。
