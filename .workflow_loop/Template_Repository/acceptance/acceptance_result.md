# 主题验收结果文档模板

本模板定义 `acceptance/<topic>_result.md` 最终记录什么。每个验收主题生成一份结果文件。

```markdown
# 【主题验收结果】<主题名称>

- 工作流编号：<当前 workflow_id>
- 验收结果：通过 | 未通过

## 1. 验收依据

- [主题验收计划](./<topic>_plan.md)
- [主题测试结果](../qa/<topic>_result.md)
- [需求交付追踪表](../traceability.md)

## 2. 验收条件结果

### AC-01：<验收条件名称>

- 验收条件：<引用验收计划中的具体条件>
- 实际结果：<实际观察或核实到的结果>
- 判定：通过 | 未通过 | 阻塞
- 证据：<别人可以复核的证据>

## 3. 未通过或阻塞

暂无

## 4. 上下游文档

- <本次验收使用的上游和产生的下游文档链接>
```

## 完成前检查

- 是否绑定当前工作流编号。
- 是否覆盖验收计划中的全部适用验收条件。
- 每条条件是否写明实际结果、判定和可复核证据。
- 是否存在未通过或阻塞却把总验收结果写成“通过”的情况。
- 是否用“功能正常”“符合预期”等空泛结论代替实际结果。
- 是否混入新的产品规则、代码方案或实施步骤。
