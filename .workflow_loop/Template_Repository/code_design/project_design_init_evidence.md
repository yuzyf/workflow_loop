# 项目设计初始化调查证据文档模板

本模板定义 `spec/项目设计初始化证据.md` 最终记录什么。它只保存本次项目设计初始化实际检查的代码、测试和运行证据，不替代产品文档或代码架构设计文档。

```markdown
# 项目设计初始化调查证据

- 工作流编号：<当前 workflow_id，也就是当前工作流编号>
- 代码检查状态：已完成

## 1. 已检查代码

| 代码路径 | 检查内容 | 得到的事实 |
|---|---|---|
| `src/...` | <检查了哪个入口、判断或调用链> | <从代码中确认了什么> |

## 2. 测试与运行记录

- 运行条件：具备 | 不具备
- 执行状态：已执行 | 未执行
- 执行命令：<实际执行的测试、构建或启动命令；未执行时写“暂无”>
- 执行结果：通过 | 失败 | 部分通过 | 未执行
- 结果摘要：<观察到的结果；未执行时写“暂无”>
- 未执行原因：<执行过时写“暂无”；未执行时写具体阻塞原因>
- 未验证范围：<没有运行确认的行为；全部确认时写“暂无”>

## 3. 产品与代码设计校准结果

<说明产品功能、规则、使用过程和异常怎样根据代码检查与运行结果写入产品文档和代码架构设计文档。>
```

## 完成前检查

- 是否绑定当前工作流编号。
- 是否至少列出一个真实存在的代码文件，并写清检查内容和得到的事实。
- 运行条件为“具备”时，是否记录实际命令、执行结果和结果摘要。
- 运行条件为“不具备”时，是否写清未执行原因和未验证范围。
- 是否说明产品文档和代码架构设计文档怎样根据证据完成校准。
- 不写没有实际检查过的代码、测试或运行结果。
