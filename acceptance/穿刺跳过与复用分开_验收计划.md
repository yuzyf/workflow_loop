# 【验收主题】穿刺跳过与复用分开

- 工作流编号：2026-09-09-0901-product_change
- 验收主题：穿刺跳过与复用分开

<a id="1-本次需求与验收目标"></a>
## 1. 本次需求与验收目标

<a id="需求来源"></a>
### 需求来源

- 用户在 2026-09-10 提出：从 impl 返回 spec 改设计重走 spike 时，skip 导致本工作流已登记的穿刺资产被连坐，做过的活无法引用，只能改状态文件救火。

<a id="验收目标"></a>
### 验收目标

- spike 跳过拆成两个语义不同的操作：skip 只表达本轮不做穿刺（有本轮资产时先警告后果），reuse 复用既有结论且追踪表引用不被连坐；返回重走时 AI 有明确决策树可选路径。

<a id="2-产品设计依据"></a>
## 2. 产品设计依据

- [功能_验证技术不确定性](../spec/功能_验证技术不确定性.md) R30（跳过与复用分开）、R31（复用依据与失效条件）、R32（返回重走决策树）。

<a id="3-验收范围"></a>
## 3. 验收范围

<a id="本主题验收"></a>
### 本主题验收

- skip 在有本轮登记资产时的执行前警告行为。
- reuse 命令的复用语义和追踪表引用不受连坐。
- 复用依据缺失或为空时按内容问题拒绝的校验行为。
- spike 材料清单中的返回重走决策树三条路径。

<a id="本主题不验收"></a>
### 本主题不验收

- 历史轮次资产的跨轮复用（既有 R27/R29 规则）。
- 穿刺资产的登记与清理（既有规则）。
- 主题一、二、三的验收内容。

<a id="4-验收条件"></a>
## 4. 验收条件

<a id="ac-01"></a>
<a id="ac-01有本轮资产时-skip-先警告"></a>
### AC-01：有本轮资产时 skip 先警告

- 开始前状态：当前工作流已登记穿刺资产至少 1 个（state 中 spike_assets 含当前工作流编号的记录）
- 触发动作：用户决定跳过穿刺，AI 执行 workflow gate spike --skip
- 可检查结果：命令的完整输出文本，包含警告内容（如有）、跳过结果和下一步提示的全部内容
- 通过标准：执行前打印警告，包含三项内容：已登记资产数量、skip 将导致验收计划无法引用它们、需要复用请用 --reuse；警告先于跳过动作出现
- 不通过标准：静默跳过，事后验收计划引用资产时才被追踪表校验拒绝（连坐）
- 产品设计依据：[验证技术不确定性 R30](../spec/功能_验证技术不确定性.md#r-30)

<a id="ac-02"></a>
<a id="ac-02reuse-复用不被连坐"></a>
### AC-02：reuse 复用不被连坐

- 开始前状态：当前工作流已登记穿刺资产至少 1 个，AI 已说明每个被复用穿刺项为什么在当前设计下仍然成立（复用依据），用户已确认
- 触发动作：AI 执行 workflow gate spike --reuse
- 可检查结果：命令输出、状态记录、后续验收计划环节对既有穿刺资产引用的校验结果
- 通过标准：跳过新穿刺并推进到下一环节；状态记录复用决定；后续追踪表校验对本工作流既有穿刺资产的引用正常通过，不报“本轮已跳过新穿刺，不能引用当前工作流新登记的穿刺资产”
- 不通过标准：reuse 后引用本工作流既有资产仍被拒绝；或 reuse 命令不存在、无法执行
- 产品设计依据：[验证技术不确定性 R30](../spec/功能_验证技术不确定性.md#r-30)、[验证技术不确定性 R31](../spec/功能_验证技术不确定性.md#r-31)

<a id="ac-03"></a>
<a id="ac-03复用无依据被拒绝"></a>
### AC-03：复用无依据被拒绝

- 开始前状态：用户执行 --reuse，但 AI 没有说明任何被复用结论为什么仍然成立（复用依据缺失）
- 触发动作：程序校验复用登记
- 可检查结果：命令的完整输出文本，包含警告内容（如有）、跳过结果和下一步提示的全部内容
- 通过标准：按内容问题拒绝，指出必须补齐每个被复用穿刺项的复用依据
- 不通过标准：无依据静默复用通过
- 产品设计依据：[验证技术不确定性 R31](../spec/功能_验证技术不确定性.md#r-31)

<a id="ac-04"></a>
<a id="ac-04spike-材料含决策树"></a>
### AC-04：spike 材料含决策树

- 开始前状态：轮次处于 spike 环节（包括从下游退回重走 spike 的场景）
- 触发动作：AI 执行 workflow discuss 加载 spike 环节材料
- 可检查结果：材料清单输出全文
- 通过标准：输出包含返回重走决策树的三条路径：设计变更引入新技术不确定性时重新穿刺；没有引入且本工作流无既有穿刺时 skip；没有引入但本工作流有既有穿刺时 reuse
- 不通过标准：材料清单没有决策树内容，AI 只能靠翻源码或猜来选择路径
- 产品设计依据：[验证技术不确定性 R32](../spec/功能_验证技术不确定性.md#r-32)
