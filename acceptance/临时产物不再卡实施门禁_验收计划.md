# 【验收主题】临时产物不再卡实施门禁

- 工作流编号：2026-09-09-0901-product_change
- 验收主题：临时产物不再卡实施门禁

<a id="1-本次需求与验收目标"></a>
## 1. 本次需求与验收目标

<a id="需求来源"></a>
### 需求来源

- 用户在 2026-09-09 提出：讨论过程中 AI 生成的临时原型图会影响门禁，造成反复卡住。

<a id="验收目标"></a>
### 验收目标

- 讨论产品设计时生成的原型图、界面草图等临时文件，无论放在项目哪个位置、什么格式，都不再被实施门禁算成实际改动；临时产物有专门存放目录且完全不参与检查。

<a id="2-产品设计依据"></a>
## 2. 产品设计依据

- [功能_实施并保护项目修改](../spec/功能_实施并保护项目修改.md) R34（实际改动白名单）、R35（草稿目录约定）。

<a id="3-验收范围"></a>
## 3. 验收范围

<a id="本主题验收"></a>
### 本主题验收

- 实际改动清单的过滤规则（白名单制、与观察快照同源）。
- 草稿目录 .workflow_loop/scratch/<轮次编号>/ 的豁免。
- 非代码后缀项目的项目级配置扩展。
- 放错位置的临时产物的提示行为。

<a id="本主题不验收"></a>
### 本主题不验收

- 删除文件的处理（由主题“删除文件不再阻塞基线准备”验收）。
- 退回后核对无需修改的出口（由主题“退回核对无需修改有合法出口”验收）。
- 临时产物目录的创建时机和清理策略（由最终全量回归和既有清理规则负责）。

<a id="4-验收条件"></a>
## 4. 验收条件

<a id="ac-01"></a>
<a id="ac-01非代码临时文件不算实际改动"></a>
### AC-01：非代码临时文件不算实际改动

- 开始前状态：项目工作区存在未提交的 HTML 原型图（例如项目根目录下的 原型.html），该文件未在任何环节登记，也不属于任何代码后缀
- 触发动作：AI 执行 workflow gate impl（实施门禁），程序计算本轮实际改动清单
- 可检查结果：门禁输出中的实际改动与实施记录核对详情，逐项列出被认定为本轮实际改动的路径
- 通过标准：原型图路径不出现在实际改动清单，也不出现“检测到实际改动，但实施记录没有说明该文件”报错；同一工作区内的真实代码文件照常被识别为实际改动
- 不通过标准：原型图被列为未说明的实际改动并导致门禁失败；或代码文件也被漏掉
- 产品设计依据：[实施并保护项目修改 R34](../spec/功能_实施并保护项目修改.md#r-34)

<a id="ac-02"></a>
<a id="ac-02草稿目录完全不参与检查"></a>
### AC-02：草稿目录完全不参与检查

- 开始前状态：.workflow_loop/scratch/<当前轮次编号>/ 目录下存在原型图和任意格式草稿文件
- 触发动作：AI 执行 workflow gate impl（实施门禁），程序计算实际改动清单和快照差异
- 可检查结果：门禁输出与快照差异清单中列出的路径
- 通过标准：草稿目录内的文件不出现在任何改动清单、快照差异或门禁报错中
- 不通过标准：草稿目录内容被计入实际改动或触发任何门禁失败
- 产品设计依据：[实施并保护项目修改 R35](../spec/功能_实施并保护项目修改.md#r-35)

<a id="ac-03"></a>
<a id="ac-03非代码后缀项目可登记扩展"></a>
### AC-03：非代码后缀项目可登记扩展

- 开始前状态：某项目的正式产物是 .html 页面（.html 不在代码后缀清单内），项目级配置尚未登记该后缀，此时修改 .html 文件不会被算成实际改动
- 触发动作：维护者在项目级配置登记 .html 为扩展后缀后，AI 执行 workflow gate impl（实施门禁）
- 可检查结果：门禁输出中的实际改动清单
- 通过标准：登记后 .html 文件的真实修改被算成实际改动，出现在改动清单中
- 不通过标准：登记后缀后修改 .html 文件仍被忽略，真实改动漏检
- 产品设计依据：[实施并保护项目修改 R34](../spec/功能_实施并保护项目修改.md#r-34)

<a id="ac-04"></a>
<a id="ac-04放错位置提示不阻塞"></a>
### AC-04：放错位置提示不阻塞

- 开始前状态：原型图放在项目根目录（不在草稿目录、非代码格式、未提交）
- 触发动作：AI 执行 workflow gate impl（实施门禁）
- 可检查结果：门禁命令的完整输出文本，包含实际改动清单和逐项核对详情两部分的全部内容
- 通过标准：门禁不因原型图失败；输出中附一句临时产物存放约定提示（指向草稿目录）
- 不通过标准：门禁因原型图失败；或提示不存在；或提示变成阻塞条件
- 产品设计依据：[实施并保护项目修改 R35](../spec/功能_实施并保护项目修改.md#r-35)

## 5. 完成判定
