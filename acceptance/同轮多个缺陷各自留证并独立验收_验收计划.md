# 【验收主题】同轮多个缺陷各自留证并独立验收

- 工作流编号：2026-09-07-0700-product_change
- 验收主题：同轮多个缺陷各自留证并独立验收

<a id="1-本次需求与验收目标"></a>
## 1. 本次需求与验收目标

<a id="需求来源"></a>
### 需求来源

- 用户要求同轮修复多个缺陷，并指出第二份缺陷表错误使用第一份生成凭据。
- 用户授权 AI 代行本轮日常确认与核对；未要求本轮提交、推送或发布。

<a id="验收目标"></a>
### 验收目标

- 同轮每个缺陷都能保留独立事实、凭据和验收结果，不需要因为缺陷数量增加而重新开工。

<a id="2-产品设计依据"></a>
## 2. 产品设计依据

- [复现产品缺陷 R11](../spec/功能_复现产品缺陷.md#r-11)、[R18](../spec/功能_复现产品缺陷.md#r-18)、[R19](../spec/功能_复现产品缺陷.md#r-19)、[R20](../spec/功能_复现产品缺陷.md#r-20)

<a id="3-验收范围"></a>
## 3. 验收范围

<a id="本主题验收"></a>
### 本主题验收

- 验收多主题建表、正式缺陷生成、索引合并、凭据隔离、旧表兼容、错误拒绝和按主题退回。

<a id="本主题不验收"></a>
### 本主题不验收

- 不改变已确认产品行为的定义，不取消整轮回归；其他四项遗留问题由各自主题验收。

<a id="4-验收条件"></a>
## 4. 验收条件

<a id="ac-01"></a>
<a id="ac-01独立生成多份缺陷"></a>
### AC-01：独立生成多份缺陷

- 开始前状态：本轮已确认两个不同缺陷，每份记录表都填有独立主题和完整复现事实。
- 触发动作：AI 通过按表生成入口依次生成两份记录，再更新并重新生成其中一份。
- 可检查结果：本轮两个正式缺陷文档、各自凭据和共享索引均存在，变更只进入指定缺陷。
- 通过标准：两份都能首次生成且重复生成稳定；没有凭据冲突，未改主题的事实和入口保留。
- 不通过标准：第二份因第一份凭据被拒绝，重生成覆盖其他缺陷，或索引丢失任一入口均不通过。
- 产品设计依据：[复现产品缺陷 R11](../spec/功能_复现产品缺陷.md#r-11)、[R18](../spec/功能_复现产品缺陷.md#r-18)、[R19](../spec/功能_复现产品缺陷.md#r-19)、[R20](../spec/功能_复现产品缺陷.md#r-20)

<a id="ac-02"></a>
<a id="ac-02旧表兼容且错误零覆盖"></a>
### AC-02：旧表兼容且错误零覆盖

- 开始前状态：项目含已填写旧单表、初始空表或新增主题表，也可能存在重复主题、缺表和无效程序字段。
- 触发动作：AI 通过建表及阶段检查入口补齐和检查本轮记录。
- 可检查结果：已填旧表继续使用原路径和冻结栏目，空占位表不会冒充缺陷；错误明确指向对应表。
- 通过标准：旧表版本一至三均可继续；有效新表独立处理；重复、缺失、标识冲突和篡改均拒绝且不覆盖正式事实。
- 不通过标准：旧表被强制迁移，已登记但不完整的主题被跳过，或非法输入改写正式事实均不通过。
- 产品设计依据：[复现产品缺陷 R11](../spec/功能_复现产品缺陷.md#r-11)、[R18](../spec/功能_复现产品缺陷.md#r-18)、[R19](../spec/功能_复现产品缺陷.md#r-19)、[R20](../spec/功能_复现产品缺陷.md#r-20)

<a id="ac-03"></a>
<a id="ac-03退回只清除受影响主题"></a>
### AC-03：退回只清除受影响主题

- 开始前状态：同轮两个缺陷已有独立测试及验收结果，只有一个主题需重新实施。
- 触发动作：AI 通过返回上游入口指定受影响主题，并继续完成后续检查。
- 可检查结果：受影响主题的旧结果失效，其他主题结果保留；最终全量回归和整体验收不能沿用旧结论。
- 通过标准：原始复现事实保留，未受影响主题不被清空；任一主题未完成时整轮不能完成。
- 不通过标准：退回一个主题清除另一主题，旧结论复活，或未完成全部主题即允许收工均不通过。
- 产品设计依据：[复现产品缺陷 R11](../spec/功能_复现产品缺陷.md#r-11)、[R18](../spec/功能_复现产品缺陷.md#r-18)、[R19](../spec/功能_复现产品缺陷.md#r-19)、[R20](../spec/功能_复现产品缺陷.md#r-20)

<a id="5-完成判定"></a>
## 5. 完成判定

- 本主题 3 条验收条件全部通过，真实结果和当前机器证据一致后完成；不接受部分通过。
