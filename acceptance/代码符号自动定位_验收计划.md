## 1. 本次需求与验收目标

- 最终设计同步的代码位置与验证位置由程序解析真实代码符号核对，消除 update_code_design 环节曾 38 连败的 AI 手写 文件::符号 格式问题。

<a id="2-产品设计依据"></a>
## 2. 产品设计依据

- 维护代码设计功能的最终同步规则；tree-sitter 方案经对比后改用 Python 标准库 ast 解析（零新依赖、同覆盖 Python 符号，非 Python 文件按文件级核对）。

<a id="3-验收范围"></a>
## 3. 验收范围

<a id="本主题验收"></a>
### 本主题验收

- 符号索引建立、引用核对、异常路径三个行为。

<a id="本主题不验收"></a>
### 本主题不验收

- 非 Python 语言（JS/Go 等）的符号级解析（按文件级核对处理）；架构文档正文的自动改写（仍由正文变更表驱动）。

<a id="4-验收条件"></a>
## 4. 验收条件

<a id="ac-01"></a>
<a id="ac-01设计同步代码位置程序校验"></a>
### AC-01：设计同步代码位置程序校验

- 开始前状态：最终设计同步阶段，架构正文变更表或同步说明中包含代码位置引用（文件::符号格式）
- 触发动作：AI 提交设计同步门禁（workflow gate update_code_design）
- 可检查结果：门禁对代码位置引用的校验结果
- 通过标准：程序用代码符号索引核对每个 文件::符号 引用：文件存在且符号在该文件真实存在（函数、类、方法）时通过；不需要 AI 保证格式，程序给出核对事实
- 不通过标准：引用的文件不存在或符号在文件中不存在时，报错给出该文件真实存在的相近符号供修正
- 产品设计依据：[维护代码设计 R12](../spec/功能_维护代码设计.md#r-12)

<a id="ac-02"></a>
<a id="ac-02符号索引真实解析"></a>
### AC-02：符号索引真实解析

- 开始前状态：项目内存在 Python 源码文件（含函数、类、类方法）
- 触发动作：程序建立代码符号索引（设计同步门禁触发）
- 可检查结果：索引内容与真实代码对比
- 通过标准：索引包含每个 Python 文件的模块级函数、类、类的直接方法，格式为 文件::名称；解析失败的单文件跳过并记录，不中断整体索引
- 不通过标准：索引缺失真实存在的符号、包含不存在的符号、或单个文件解析失败导致整体崩溃
- 产品设计依据：[维护代码设计 R12](../spec/功能_维护代码设计.md#r-12)

<a id="ac-03"></a>
<a id="ac-03非-python-与不存在文件处理"></a>
### AC-03：非 Python 与不存在文件处理

- 开始前状态：架构引用中存在非 Python 文件路径或不存在的文件
- 触发动作：程序核对这类引用
- 可检查结果：查看门禁输出的核对结论：非 Python 引用与不存在文件的各自处理结果
- 通过标准：非 Python 文件跳过符号级核对（只查文件存在）；不存在的文件报错并指出路径无效；验证位置中的 tests/ 测试入口按真实测试函数核对
- 不通过标准：对非 Python 文件强做符号解析报错、或放过不存在的文件
- 产品设计依据：[维护代码设计 R12](../spec/功能_维护代码设计.md#r-12)
