# 【验收主题】生成文档列序与结果引用符合模板规则

- 工作流编号：2026-08-30-1025-bugfix
- 验收主题：生成文档列序与结果引用符合模板规则

## 1. 本次需求与验收目标

### 需求来源

- 用户报告：上一修复轮生成的实施记录下游测试结果引用停留待生成；测试条件覆盖表多出直白测试名称列（bug/缺陷_生成文档列序与结果引用符合模板规则.md）。

### 验收目标

- 表模式生成的测试计划覆盖表与模板列序完全一致；测试结果文档真实生成后，实施记录中的对应下游引用自动回补为可导航链接。

## 2. 产品设计依据

- 工作记录表与正式文档生成功能：模板为生成文档的结构基准（Template_Repository/qa/test_plan.md）；工作流生命周期规范：文档链接要求（Standardized_Repository/global/workflow_lifecycle.md）。

## 3. 验收范围

### 本主题验收

- 测试计划覆盖表 13 列列序对齐模板；实施记录的测试结果下游引用在结果文档生成后被回补为链接。

### 本主题不验收

- 缺陷复现记录本身的格式（复现阶段产物）；表模式其余渲染行为（上一轮已验收）。

<a id="4-验收条件"></a>
## 4. 验收条件

<a id="ac-01"></a>
### AC-01：测试计划覆盖表列序与模板一致

- 开始前状态：上一修复轮生成的测试计划文档覆盖表为 14 列（多出直白测试名称列）
- 触发动作：用户执行 workflow gate qa 打开生成的测试计划文档第 1 章，与模板 qa/test_plan.md 第 1 章逐列对照
- 可检查结果：覆盖表表头逐列与 Template_Repository/qa/test_plan.md 第 1 章对照
- 通过标准：覆盖表恰为模板 13 列且列名列序一致；测试项列承载锚点、TC 编号与直白名称，不出现独立直白测试名称列
- 不通过标准：表头多列、少列或列序不一致
- 产品设计依据：[工作记录表与正式文档生成 R16](../spec/功能_工作记录表与正式文档生成.md#r-16)、[R18](../spec/功能_工作记录表与正式文档生成.md#r-18)：生成文档以模板为结构基准，覆盖表列名列序与模板一致

<a id="ac-02"></a>
### AC-02：结果文档生成后实施记录引用回补

- 开始前状态：上一修复轮实施记录的测试结果下游行停留（待生成），而结果文档已生成
- 触发动作：qa 门禁生成测试结果文档后，AI 打开实施记录文档第 4 节上下游文档表，检查测试结果行
- 可检查结果：该下游行是否由（待生成）升级为指向真实文件的 Markdown 链接
- 通过标准：结果文档存在时实施记录对应行为真实链接；结果文档不存在时保持普通路径加（待生成）
- 不通过标准：结果文档已存在而引用仍是（待生成）
- 产品设计依据：[工作记录表与正式文档生成 R18](../spec/功能_工作记录表与正式文档生成.md#r-18)、[工作流生命周期规范 文档链接要求](../.workflow_loop/Standardized_Repository/global/workflow_lifecycle.md)：文件真实生成后才改成可导航链接

## 5. 完成判定

- AC-01 与 AC-02 的自动化测试全部通过且最终全量回归通过后，本主题完成。
