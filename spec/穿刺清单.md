## SP-001 验证固定版本 uv 的隔离安装

- 真实场景：macOS 或 Linux 的 Bash 安装脚本、Windows PowerShell 安装脚本下载固定版本 uv，校验发布方摘要，使用用户已经安装的 Python，把 workflow-loop 0.1.0 安装到工具环境并立即执行身份检查。
- 要验证的不确定性：从官方发布单独下载的固定 uv，能否在显式指定 Python、禁止自动下载 Python、隔离工具目录且不修改用户 PATH 的情况下安装本项目构建的 0.1.0 包，并从隔离命令目录执行新安装的 `workflow`。
- 验证结果用于决定什么：决定安装脚本锁定的 uv 版本、资产路径、摘要来源、环境变量和 `uv tool install` 参数；失败时需要修改代码设计中的安装工具方案。
