### 2.1 预期产品结果

项目发布新版本后，维护版本判断测试仍以当前包版本作为同版本发布样本并通过，同时继续验证低版本、预发布版本、缺失版本和 PyPI 与 GitHub Release 来源不一致时被拒绝。`src/workflow_loop/cli.py` 中的版本解析和降级保护不发生变化。
