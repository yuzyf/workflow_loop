<a id="32-实施中问题与处理"></a>
### 3.2 实施中问题与处理

- 实施中发现 ProjectState 新字段会让旧作废清单快照校验失败（snapshot_managed_fields 缺 extra_code_suffixes 报错），已兼容：_validate_managed_fields 对旧快照缺该字段按空列表处理，restore 用 fields.get 带默认值——属于主题一改动引发的连带修复，修复事实记录在主题一表对应行。
- 本轮自身实证：进场后修改的代码（九个文件全部有未提交差异）通过 prepare 成功，复用上周上线的 Git 自证出口（快照=HEAD 用 HEAD 字节副本）；本改动新增的删除分支在同一次 prepare 中未触发（本轮无删除文件），行为由既有自证测试和开轮前真实 Git 仓库验证覆盖。
- QA 测试执行前发现实现缺陷：删除分支初版给 Git 自证传 expected_content_hash=None，这会要求工作区干净（未提交的删除算差异）导致已提交文件删除时自证失败；已修复为传进场快照记录的 content_hash（哈希对比路径不依赖工作区状态，与开轮前真实验证的行为一致），test_deleted_committed_file_uses_git_baseline 修复后通过。
